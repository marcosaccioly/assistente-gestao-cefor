# 99-automelhoria/

Cada comando (`/bom-dia`, `/sessao`, `/executar`) deixa uma linha em `_entrada/AAAA-MM-DD.md`: o que faltou no painel, o que a triagem errou, que decisão não coube no catálogo, quanto tempo levou.

Duas utilidades:

- **Para você:** "isso é recorrente", "isso é ruído", "faltou o bloco X" viram mudança nos seus `fluxos/`.
- **Para todos:** o que for melhoria do próprio assistente (um comando que travou, um campo que falta), leve para quem mantém o modelo. É assim que a próxima versão chega melhor para todos os gestores.
